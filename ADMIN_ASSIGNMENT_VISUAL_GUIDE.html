1 Logout from Agent Account

Click the "Logout" button in the top right corner of the page.

💡 Tip: You need admin privileges to assign complaints. Agents cannot assign complaints to themselves.
2 Login as Admin (or Create Admin Account)

Option A: If you already have an admin account, login with those credentials.

Option B: If you DON'T have an admin account:

  1. Click "Sign Up"
  2. Fill the registration form:
    • Name: Admin User (or any name)
    • Email: admin@test.com
    • Password: Your password
    • Phone: Any 10-digit number
    • User Type: Select "Admin" ← CRITICAL!
  3. Click "Register"
  4. Now login with admin@test.com and your password
⚠️ Important: Make sure you select "Admin" as the User Type during signup. If you select "Customer" or "Agent", you won't be able to assign complaints!
3 Navigate to Admin Dashboard

After logging in as admin, you'll automatically be redirected to the admin dashboard.

URL should be: http://localhost:3000/admin-dashboard

5 Assign Each Complaint to "Yadalla Bhargavi"

You'll see a table with all pending complaints. Here's what it looks like:

✋ For EACH Complaint Row, Do This:

  1. Click the dropdown that says "Select Agent"
  2. Choose "Yadalla Bhargavi" from the list

  4. Wait for alert: "Complaint assigned successfully"
  5. Click OK on the alert
  6. Repeat for the next complaint row
⚠️ Important: You must do this for ALL 3 complaints individually. Don't skip any!

⚠️ Troubleshooting

Problem: "Yadalla Bhargavi" not appearing in dropdown

Cause: No agents found or the account wasn't created with userType "agent"

Solution:

  1. Make sure "Yadalla Bhargavi" account was created with User Type: "Agent"
  2. If not, create a new account with User Type: Agent

Problem: No pending complaints showing

Cause: Complaints already assigned OR no complaints submitted

Solution:

  1. Check "Assigned Complaints" accordion - they might already be assigned
  2. If no complaints anywhere, submit new complaints as customer first

Problem: Assignment button does nothing

Cause: No agent selected from dropdown

Solution: Make sure you SELECT an agent from the dropdown BEFORE clicking Assign

📝 Quick Summary

  1. Logout from agent account
  2. Login as ADMIN (or create admin account)
  3. Go to Admin Dashboard
  4. Find "Pending Complaints (3)" section

  6. Logout from admin
  7. Login as agent "Yadalla Bhargavi"
  8. Check Agent Dashboard - All 3 complaints will appear!
